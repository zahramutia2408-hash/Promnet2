# Personal Website — Zahra Mutia Rahmah

## 📌 Tentang Website

**Personal Website** ini merupakan website pribadi yang dibuat sebagai media untuk memperkenalkan profil, karya, pengalaman, serta aktivitas yang pernah saya lakukan selama menempuh pendidikan.

Website ini dikembangkan sebagai bagian dari **penugasan mata kuliah Pemrograman Internet**. Selain sebagai pemenuhan tugas perkuliahan, website ini juga menjadi sarana untuk menerapkan pembelajaran mengenai pengembangan website menggunakan HTML serta pengelolaan project menggunakan Git dan GitHub.

Website personal ini memiliki **lima halaman utama**, yaitu:

### 🏠 1. Home
Halaman utama yang menjadi tampilan awal website. Bagian ini memberikan gambaran singkat mengenai diri saya dan memperkenalkan website personal secara keseluruhan.

### 👤 2. About
Halaman yang berisi informasi mengenai profil diri, latar belakang pendidikan, minat, serta informasi lain yang berkaitan dengan diri saya.

### 💻 3. Project
Halaman yang menampilkan berbagai project yang pernah saya kerjakan, baik dalam kegiatan perkuliahan maupun project lainnya. Setiap project dilengkapi dengan deskripsi, gambar, teknologi yang digunakan, serta status pengerjaannya.

### 📩 4. Contact
Halaman yang menyediakan informasi dan form kontak sehingga pengunjung dapat mengirimkan pesan atau menghubungi saya.

### 🌱 5. Experience & Activities
Halaman yang berisi berbagai pengalaman dan aktivitas yang pernah saya ikuti selama menempuh pendidikan, seperti kepanitiaan, organisasi, volunteer, seminar, workshop, pelatihan, kompetisi, dan kegiatan lainnya. Dokumentasi atau sertifikat kegiatan juga dapat ditampilkan sebagai pendukung.

---

## 🎯 Tujuan Pembuatan

Website ini dibuat dengan beberapa tujuan, yaitu:

- Memperkenalkan profil dan latar belakang diri.
- Menampilkan project dan karya yang pernah dibuat.
- Mendokumentasikan pengalaman serta aktivitas yang pernah diikuti.
- Menerapkan konsep dasar pengembangan website.
- Mempelajari penggunaan Git dan GitHub dalam pengelolaan project.
- Membuat media portfolio pribadi yang dapat dikembangkan lebih lanjut.

---

## 🛠️ Teknologi yang Digunakan

Website ini dikembangkan menggunakan beberapa teknologi dan tools, yaitu:

- **HTML** — digunakan untuk membangun struktur dan konten website.
- **Git** — digunakan untuk mengelola perubahan pada project.
- **GitHub** — digunakan sebagai repository dan tempat penyimpanan project.
- **Visual Studio Code** — digunakan sebagai code editor dalam proses pengembangan website.
